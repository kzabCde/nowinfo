# nowinfo
NowInfo คือศูนย์รวมข่าวที่ช่วยตอบ 3 คำถาม: เกิดอะไรขึ้น → เกี่ยวข้องกับใคร → ควรติดตามอะไรต่อ มุ่งให้ผู้อ่านภาษาไทยเข้าใจความเชื่อมโยงของเหตุการณ์ระดับโลกกับชีวิต เศรษฐกิจ เทคโนโลยี พลังงาน สิ่งแวดล้อม และประเทศไทย  กลุ่มผู้ใช้เริ่มต้น: ผู้ติดตามสถานการณ์โลก นักศึกษา คนทำงาน และผู้ประกอบการที่ต้องการเปิดอ่านข่าวจากหลายหมวดในที่เดียว
